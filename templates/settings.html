Monitoring Scope & Limitations Notice

This application utilizes Python's psutil library to monitor the system running this process. When deployed inside an unprivileged Docker container, CPU and memory metrics reflect the container's visible cgroups and virtual boundaries. It does not claim connection to third-party public cloud providers (AWS, Azure, GCP) unless explicitly configured with external APIs.

DevOps Laboratory Demonstration Guide (Viva / CAT)

Step 1
Simulate Alert Trigger:

Set the CPU threshold above to 5.0% (below normal machine load) and click Save & Apply Thresholds. Return to the Dashboard and click Refresh Now. Observe that a High Load Alert is instantly generated and logged in the Alerts tab.

Step 2
Demonstrate Deduplication:

Click Refresh Now multiple times while the CPU threshold remains at 5.0%. Show the professor that no duplicate alert records are spammed into SQLite—the existing alert remains Active and updates its reading.

Step 3
Demonstrate Auto-Resolution:

Return here and set the CPU threshold back to 80.0%. Click Refresh Now on the Dashboard. Watch the active alert automatically transition to Resolved with an exact resolved_at timestamp!
